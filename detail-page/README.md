# 딱새우 꾸어칩 상세페이지

네이버 스마트스토어 / 쿠팡 업로드용 상품 상세페이지입니다. 외부 리소스 없이 `index.html` 한 파일로 동작합니다.

## 사용법

1. `index.html`을 브라우저로 엽니다.
2. 상단 바에서 판매 채널 폭을 고릅니다. **네이버 860px** / **쿠팡 780px**.
3. 실제 사진을 넣습니다. 점선으로 표시된 자리(`.slot`)를 `<img>`로 교체하세요.
4. 사진을 다 넣었으면 **사진 자리 표시**를 꺼서 안내 문구를 숨깁니다.
5. `✂ Cut 01` ~ `✂ Cut 09` 선을 기준으로 화면을 캡처해 이미지로 저장한 뒤 각 채널에 업로드합니다.

## 채널별 규격

| 항목 | 네이버 스마트스토어 | 쿠팡 |
| --- | --- | --- |
| 상세 이미지 가로 | 860px | 780px |
| 상세 이미지 세로 | 한 장당 약 5,000px 이내 | 한 장당 3,000px 이내 |
| 대표 이미지 | 1000 × 1000px | 1000 × 1000px |
| 파일 형식 | JPG / PNG | JPG / JPEG (GIF 불가) |

## 사진 넣기

HTML은 이미 배선되어 있습니다. **아래 경로에 아래 파일명 그대로 저장하면 자동으로 붙습니다.**
파일이 없는 자리는 점선 안내가 대신 표시되고, 파일을 넣으면 안내가 사라지고 사진이 들어갑니다.
따로 HTML을 고칠 필요가 없습니다.

| 위치 | 저장 경로 · 파일명 | 권장 크기 |
| --- | --- | --- |
| 히어로 | `assets/03_대표이미지/딱새우꾸어칩_정면.png` | 860 × 640px |
| 딱새우 이야기 | `assets/04_상세컷/딱새우_원물.jpg` | 860 × 560px |
| 즐기는 법 | `assets/04_상세컷/맥주안주_연출.png` | 860 × 600px |
| 제품 정보 | `assets/04_상세컷/뒷면라벨.png` | 860 × 520px |

### 내려받아 저장할 파일

`AGENTS.md`의 「확보된 이미지」 표에 각 파일의 힉스필드 주소가 정리되어 있습니다.

다른 파일명을 쓰고 싶으면 `index.html`의 `<img src="...">` 값만 바꾸면 됩니다.

> 온라인 미리보기(Artifact) 링크에서는 사진이 보이지 않습니다. 그 페이지에는 이미지 파일이 함께
> 올라가 있지 않기 때문입니다. **PC에서 `index.html`을 열면 정상적으로 보입니다.**

## 업로드 전 확인할 것

포장 사진에서 읽어 옮긴 값이라 아래 항목은 품목제조보고서와 대조해주세요.

- **당류 18g (18%)** — 탄수화물 27g 중 18g이 당류인 셈이라 값이 커 보입니다. 표시 비율(18%)과는 맞아떨어지지만 한 번 확인이 필요합니다.
- **원재료명 전문** — 포장 뒷면 작은 글씨 중 일부(향신료, 첨가물 순서)는 요약해 옮겼습니다. 실제 표시사항 문구 그대로 교체하세요.
- **제조원 주소** — 부산시 사하구까지만 표기했습니다. 상세 주소를 채워주세요.
- **동일 제조시설 알레르기 문구** — 포장에 적힌 원문 그대로 교체하세요.
- **배송 · 교환 · 반품** — 실제 운영 정책에 맞게 수정하세요.

## 문구 작성 시 주의

식품 등의 표시·광고에 관한 법률상 일반식품에 질병 예방·치료, 건강기능식품 오인 표현은 쓸 수 없습니다. `면역력`, `다이어트`, `혈행 개선` 같은 표현은 추가하지 마세요. 현재 페이지 문구는 모두 표시사항에 근거한 사실 서술로만 작성되어 있습니다.
