## 3. 문구 규칙 (반드시 지킬 것)

### 쓰면 안 되는 표현

식품 등의 표시·광고에 관한 법률상 일반식품에는 아래를 쓸 수 없습니다. 과태료 사례가 많은 영역입니다.

- 질병 예방·치료 암시: `면역력`, `혈행 개선`, `혈압`, `염증`, `숙취 해소`
- 건강기능식품 오인: `기능성`, `영양제`, `～에 좋은`
- 의약품 오인 표현 전반
- `다이어트`, `체지방` 등 체중 감소 암시

### 제품 특성상 특히 주의할 것

칩의 몸통은 **실꼬리돔 연육(베트남산)** 이고, 딱새우는 **조미 원료**로 들어갑니다.
따라서 아래 표현은 사실과 다릅니다.

- ❌ "제주 딱새우가 통째로"
- ❌ "딱새우 100%"
- ❌ "제주산 새우로 만든 칩"
- ⭕ "실꼬리돔 연육 75.57%에 국산 딱새우분말로 맛을 낸"
- ⭕ "딱새우분말과 꽃게가루가 들어간 복합조미식품으로 맛을 냄"

원산지도 혼동하기 쉽습니다. **딱새우분말과 꽃게가루는 국산, 연육은 베트남산**입니다.
전분·소금·대두유는 대부분 외국산이라 "국내산 원료" 같은 뭉뚱그린 표현은 쓸 수 없습니다.

## 4. 디자인 시스템

`index.html`의 `:root`에 토큰으로 정의되어 있습니다. 새 이미지를 만들 때도 같은 값을 쓰세요.

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--red` | `#E12B20` | 딱새우 레드 · 히어로 배경, 강조 |
| `--red-deep` | `#A81811` | 껍질 딥레드 · 주의사항 섹션 |
| `--yellow` | `#FFC72C` | 로고 옐로 · 알레르기 칩, 아이브로우 |
| `--cream` | `#FBF4EC` | 웜 크림 · 보조 배경 |
| `--gold` | `#D89A4E` | 칩 골드 · 사진 자리 테두리 |
| `--ink` | `#1F1A18` | 웜 잉크 · 본문 |

- **서체**: 시스템 한글 스택 (Pretendard → Apple SD Gothic Neo → 맑은 고딕). Artifact CSP가 폰트 CDN을 막고 한글 웹폰트는 data URI로 넣기엔 용량이 커서 시스템 폰트로 갑니다. 위계는 굵기·크기·자간으로만 만듭니다.
- **구조 장치**: 봉투 가장자리의 절취선(CUT)을 섹션 구분자로 씁니다. 장식이 아니라 **실제로 캡처를 자르는 지점**입니다. 새 섹션을 넣으면 Cut 번호를 다시 매기세요.
- **번호 매기기**: `01 / 02 / 03` 마커는 "제조 3단계"에만 씁니다. 실제 순서가 있는 내용에만 허용합니다.

## 6. 이미지 작업 (힉스필드 MCP)

### 쓸 수 있는 것

| 작업 | 도구 | 비고 |
| --- | --- | --- |
| 배경 제거 | `remove_background` | 실사 그대로라 왜곡 없음. 가장 안전 |
| 배경만 생성한 연출컷 | `generate_image` + `marketing_studio_image` | 제품은 실물, 배경만 생성 |
| 해상도 향상 | `upscale_image` | 뒷면 라벨 글자 가독성 확보용 |
| 순수 크롭 | `outpaint_image` (음수 값) | 전부 크롭이면 모델을 안 거치고 무료 처리 |

`generate_image`의 `medias[].value`에는 **URL이 아니라 media_id 또는 job_id**를 넣습니다.

### 하지 말 것

- **AI 정면화·각도 보정 금지 (2026-08-14 실패 확인).** `nano_banana_pro`(내부 `nano_banana_2`)에
  누끼 정면컷을 레퍼런스로 넣고 "모든 한글을 레퍼런스와 동일하게 유지"를 명시해 2안을 생성했으나,
  **두 안 모두 포장의 한글이 전부 깨져 판독 불가**했습니다. 이미지 생성 모델은 픽셀을 옮기는 게 아니라
  그림을 다시 그리므로, 획이 조밀한 한글은 프롬프트로 막을 수 없습니다. 재시도해도 결과는 같습니다.
  기울기는 **포토샵에서 회전·크롭·원근 변형으로만** 잡으세요. 픽셀을 옮기는 방식이라 글자가 손상되지 않습니다.
- **칩 클로즈업 생성 금지.** 실제 제품과 다른 모양·색의 칩이 나옵니다. 식품 이미지가 실물과 다르면 표시광고법 위반이자 반품 사유입니다. 봉지를 뜯어 직접 촬영하세요.
- **딱새우 원물 컷 생성 금지.** 딱새우(표준명 가시발새우)는 집게다리의 붉은 줄무늬 4개가 특징인데 AI는 보통 일반 새우로 그립니다. 유료 스톡의 실사진을 쓰세요.
- 정면화·보정 프롬프트에는 항상 **"모든 한글 문자와 인쇄물을 레퍼런스와 동일하게 유지"** 지시를 넣으세요. 빠뜨리면 모델이 한글을 비슷한 모양의 가짜 글자로 다시 그립니다. 결과물은 반드시 원본과 글자를 대조해 검수하세요.

### 알려진 환경 제약

원격 컨테이너에서 작업하는 경우, 힉스필드 CDN(`d2ol7oe51mr4n9.cloudfront.net`,
`d8j0ntlcm91z4.cloudfront.net`)이 네트워크 정책에서 차단되어 **생성 결과를 저장소로 직접 내려받을 수 없습니다.**
결과물은 힉스필드 화면에서 사람이 내려받아 `assets/` 하위에 넣어야 합니다.
로컬(윈도우)에서 작업할 때는 이 제약이 없습니다.
