# SNS 주간 운영

모든 데이터는 `sns-automation/`에 있다. 명령은 그 폴더에서 실행한다.

1. `node sns.js plan` 실행 → 라인별 주간 목표 대비 등록·완료 수 확인
2. `node sns.js status` 실행 → 채널별 남은 작업 확인
3. `node sns.js cost` 실행 → 이번 달 수익 대비 구독료 확인
4. 사용자에게 아래 형식으로 짧게 보고한다.
   - 이번 주 부족한 라인 (목표 − 등록)
   - 오늘 먼저 할 작업 3개와 실행할 스킬 (`/sns-music-playlist` 등)
   - 손익분기까지 남은 금액
5. 본편이 부족하면 주제 후보 2~3개를 제안하고, 사용자가 고르면 `node sns.js new <라인> "<제목>"`으로 등록한다. 주제를 임의로 확정하지 않는다.

우선순위: 쇼핑 쇼츠·블로그(빠른 현금) → 운동 영상 → 음악 플레이리스트 → 스레드.
