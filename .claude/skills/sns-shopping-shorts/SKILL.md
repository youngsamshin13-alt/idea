# 쇼핑 쇼츠 파이프라인

인자: 콘텐츠 id. 없으면 `node sns.js new shopping "<상품명>"`으로 먼저 등록한다.

## 단계
1. **상품 확정**: 상품명, 제휴 링크, 가격대, 핵심 장점 3개를 사용자에게 받는다. 링크·가격은 지어내지 않는다. 운동 영상에 나온 용품을 우선한다.
2. **대본**: 15~30초, 첫 2초 훅 → 문제 → 사용 장면 → 장점 → 행동 유도("고정 댓글 링크"). `output/<id>/script.md`에 저장한다.
3. **영상 프롬프트**: 장면별 구글 Flow 프롬프트(8초 단위)를 작성해 `output/<id>/flow-prompts.md`에 저장한다. Flow는 MCP가 없으므로 사용자가 붙여넣어 생성한다. 필요하면 Higgsfield MCP를 대안으로 제안한다.
4. **메타데이터**: 제목, 설명, 고정 댓글. 설명과 고정 댓글 첫 줄에 `config/pipelines.json`의 `disclosure.affiliate` 문구를 반드시 넣는다.
5. **파생 작업**: 같은 영상을 릴스·페이스북·스레드로 `/sns-social-repost`, 상세 리뷰는 `/sns-blog-post`.
6. 업로드가 끝나면 `node sns.js done <id> youtube-shorts`.

## 규칙
- 써보지 않은 효과·후기를 지어내지 않는다.
- 광고 표기가 없는 결과물은 완료 처리하지 않는다.
