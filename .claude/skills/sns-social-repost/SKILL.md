# 재가공 배포 파이프라인

인자: 콘텐츠 id. `node sns.js status`로 남은 채널을 확인한다.

## 채널별 결과물 (`output/<id>/social.md`에 저장)
| 채널 | 형식 | 문구 |
|---|---|---|
| YouTube 쇼츠 | 세로 15~60초 | 제목 + 해시태그 3개 |
| 인스타 릴스 | 세로 영상 | 첫 줄 훅 + 본문 3줄 + 해시태그 10~15개 |
| 인스타 카드뉴스 | 1080×1350, 6~8장 | 장별 문구 (1장 훅, 마지막 장 저장·팔로우 유도) |
| 페이스북 | 인스타 연계 게시 | 인스타 문구에서 해시태그를 줄인 버전 |
| 스레드 | 텍스트 위주 | 500자 이내, 질문으로 끝내 댓글 유도, 링크는 댓글에 |

## 단계
1. 본편 메타데이터를 읽고 위 표대로 문구를 만든다.
2. 카드뉴스 이미지가 필요하면 Abocado `abocado_generate_image` 또는 Higgsfield `generate_image`를 쓴다. 크레딧 사용 전 승인을 받는다.
3. 제휴·광고가 포함된 콘텐츠는 모든 채널 문구에 광고 표기를 넣는다.
4. 게시는 사용자가 기존에 쓰던 연동 방식으로, 사용자 확인 후 진행한다.
5. 채널마다 게시 후 `node sns.js done <id> <채널>` (채널: youtube-shorts, instagram-reels, instagram-cardnews, facebook, threads).
