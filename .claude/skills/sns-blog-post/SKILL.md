# 블로그 파이프라인

인자: 콘텐츠 id. 단독 글이면 `node sns.js new blog "<주제>"`로 먼저 등록한다.

## 단계
1. `output/<id>/` 의 brief·routine·script를 읽고 핵심 검색어 1개와 보조 검색어 3개를 정한다.
2. 구성: 제목(검색어 앞쪽) → 요약 3줄 → 본문(소제목 3~5개) → 체크리스트/표 → 마무리. 1,500~2,500자.
3. 운동 글은 유튜브 영상 삽입 위치를, 쇼핑 글은 제휴 링크 위치를 표시한다.
4. 글 맨 위에 광고 표기(`disclosure.affiliate`), 맨 아래에 AI 활용 표기를 넣는다.
5. `output/<id>/blog.md`로 저장하고, 카드뉴스용 요약 6장 문구를 함께 만든다 → `/sns-social-repost`.
6. 게시 후 `node sns.js done <id> blog`.

## 규칙
- 직접 확인하지 않은 수치·가격·후기를 쓰지 않는다. 모르면 사용자에게 묻는다.
