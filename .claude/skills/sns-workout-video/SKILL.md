# 운동 영상 파이프라인

인자: 콘텐츠 id. 없으면 `node sns.js new workout "<제목>"`으로 먼저 등록한다.

## 단계
1. **루틴 기획**: 대상(초보/중급, 연령), 부위, 시간, 동작 5~8개를 사용자와 확정한다. 동작마다 횟수·주의점을 적어 `output/<id>/routine.md`에 저장한다.
2. **영상 생성** (둘 중 사용자가 선택)
   - Higgsfield MCP: 동작별 클립을 `generate_video`로 만든다. 여러 개면 batch를 쓴다. 크레딧 사용량을 먼저 알리고 승인을 받는다.
   - Codex: `output/<id>/codex-brief.md`에 제작 지시서(장면 목록, 자막, 타이머, 길이)를 작성해 사용자가 Codex에 넘기게 한다.
3. **메타데이터**: 제목, 설명(루틴 요약 + AI 제작 표기), 태그, 썸네일 문구를 `brief.md`에 채운다.
4. **파생 작업**
   - 카드뉴스: 동작별 1장, 총 6~8장 문구 → `/sns-social-repost`
   - 블로그: 루틴 상세 글 + 관련 운동 용품 제휴 링크 → `/sns-blog-post`
   - 루틴에 쓰인 용품은 쇼핑 쇼츠 후보로 사용자에게 제안한다.
5. 업로드가 끝나면 `node sns.js done <id> youtube-workout`.

## 규칙
- 의학적 효과를 단정하지 않는다 ("~에 좋다" 대신 "~를 쓰는 동작").
- 업로드·게시는 사용자 확인 후에만 한다.
